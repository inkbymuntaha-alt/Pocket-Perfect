# Market Makers — Build Your Market

An original Musha Games business-simulation prototype, built separately from Sortaloom.

## Current prototype
- Mobile-first, single-file HTML game with no third-party assets or runtime libraries.
- Start with a small market stall and ₹150.
- Buy fruit, bread and flower supplies; serve customer orders.
- Experiment with prices, earn cash and reputation, and unlock stall upgrades.
- Daily earning targets and a day-to-day progression loop.
- Saves progress locally in the browser on the same device.
- No ads, analytics, account system, payments or in-app purchases in this prototype.

## Run
Open `index.html` in a modern mobile or desktop browser. It is a prototype, not a store-ready release.

## Originality and release notes
The working title and game concept are provisional and have not had trademark clearance. This prototype uses original code and CSS-drawn presentation, with standard emoji glyphs from the device font. Before release, replace any unsuitable platform emoji with commissioned or original artwork, verify the final name, add a real privacy policy based on actual data practices, test on target Android devices, and review each store's current policies. No approval or ban-free outcome is guaranteed.
