# Pocket Perfect: Sort & Restore

A small, original browser game prototype. Tap an object, then tap the matching basket. Earn stars and coins, unlock room decorations, and return for a daily bonus.

## Run locally

Open `index.html` in a modern browser. For install/offline features, serve the folder over HTTPS (GitHub Pages does this after deployment).

## Publish with GitHub Pages

The included workflow deploys the repository to GitHub Pages whenever you push to `main`. In the repository, open **Settings → Pages** and choose **GitHub Actions** as the build/deployment source. Then check the **Actions** tab for a successful deployment.

## Current prototype limitations

- The 500 campaign levels are generated from 20 original theme/category sets; this is a prototype, not 500 individually hand-designed levels.
- Progress is stored locally on the current device/browser. It does not sync between devices.
- The shop is a preview only. No ads, analytics, payment processing, or Google Play Billing are connected.
- This is a web/PWA prototype, not an Android APK or an approved Google Play release.
